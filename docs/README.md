## North Star

> **Xenrya should become a customizable, expressive developer companion that stays aware of meaningful development activity, feels naturally integrated into the desktop, and can grow into deeper automation and AI capabilities without sacrificing user control, privacy, performance, or personality.**

## Next Step

Begin **Phase 0 — Foundation**. Later-phase features should not be pulled into the initial implementation unless a new product decision explicitly changes the phase gate.
